# LLM-Skills
1. **ahp-decision** - Multi-criteria decision support using the Analytic Hierarchy Process. Conversational interface over pairwise comparisons, consistency checks, and sensitivity analysis.
2. **viz** - One-screen HTML infographic of the last answer, a topic, or the git diff, picking the form (flow, table, concept/system map…) via the DSRP lens. Standalone: writes a self-contained `.viz/NNN-slug.html` (styles inlined from `assets/template.html`) and opens it in the browser.
